# Edit styles — the full index

> Every editing style this workspace knows, in one place. Compiled 1 Oct 2026 from
> `.claude/skills/`, `docs/` and the memory files. **Formats** are whole-reel layouts with their own
> skill — pick ONE per job through `reel-edit`. **Variants, recipes and looks** run inside a format.
> When he says "all three styles" he means the 60-40 split, Tharun layered-head, and the split with
> camera b-roll full screen on black. When a style changes, update its skill or memory first, then
> this page.
>
> Status key: **standing** = use it · **variant** = a sanctioned version of a format ·
> **recipe** = a reusable beat, not a whole format · **reference** = studied, not built as-is ·
> **rejected** = don't.

   `paper-drawer-edit` faced the same pill and alternation questions and settled them the same way.

trigger-word DM PDF with every final · SFX only (he adds music) · text never on his face · real
numbers only. See `reel-edit` Step 3 and Step 5.
