# Motion-graphics kit (reusable)

Everything we have built as motion graphics lives in one library on the SSD:

`<media-drive>/MG-Kit/` — see its root `README.md`.

- `lf01-longform-2026-09/` — the 16:9 long-form kit: editable heroes, lockup voices, stamps, box intro, typed
  list, comment composer, tokens, logos, the `gen_data.py` cue API; 67 alpha ProRes windows + 15 full cards
  with `INDEX.md` and contact sheets; the Palmier pipeline, SFX kit, prompts, QA stills, decision log.
- `reels-9x16-2026-07-09/` — the short-form system copied from this repo (this repo stays the working
  source): all 56 reel folders, the shared components (split, follow CTA, text hook, capture card, card reel,
  logos, Onda primitives), theme, the 15 Claude Design assets with recordings, the style docs, references.
- `other-remotion-projects/` — the standalone Remotion projects copied from ~/Documents/Videos and ~/Codes (originals still in place)
  (AI Simplified episode graphics, Bengaluru Valley, Bangalore unicorn map, TryMiles launch).

Start new MG from this kit. `out/` in this repo is also a symlink to the SSD (`VideoEdits-out`).
